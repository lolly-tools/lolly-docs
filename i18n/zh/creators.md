# 面向创作者的 Lolly

你想又快又好地做出一个东西,并且要做对。Lolly 正是为此而生:填几个字段,拿到一份成品文件 - 版式、字体、规则都由工具强制执行,而不是靠你的眼力(除非你想自己动手 - 那时你手边就有一整套强大的媒体工具)。不需要设计软件,不需要等待。它运行在你自己的设备上,离线也能用。

**这对你有什么好处:** 你几分钟内就能交付,而效果看起来像花了几个小时。你永远不用等设计师排期,而且因为品牌规则已经内置,不合品牌规范的成品永远不会挂上你的名字。你只会显得又快、又精致、又可靠。

本页面会告诉你如何充分发挥 Lolly 的作用所需了解的一切。

> **你是接力赛中的一棒。** 你编写的工具不会止步于你 - 开发者可以把它接入自动化流水线([面向构建者的 Lolly](/info/builders.html)),不懂设计的同事也可以自助运行它,无需你参与就能拿到一份完成、合规的成品文件。想了解整个生命周期如何层层叠加,参见[一场活动的生命周期](/info/overview.html#the-lifecycle-of-a-campaign)。

## 为什么选择 Lolly - 你的优势

- **成品直出,不用折腾。** 工具已经知道字体、颜色、标志、间距。你只需提供文字;它把成品交还给你。没有什么需要你去猜测。
- **结构上天生正确。** 设计规则、版式约束和运行逻辑都写在模板里 - 除非工具作者刻意留出可变项,否则输出不可能偏离规范。天马行空的创作空间,却始终守在稳固的护栏之内。
- **一处设计,多种格式。** 同一个设计可以导出为 SVG、可印刷 PDF、高分辨率 PNG,或 60fps 视频。做一次,处处可用。
- **无限排列组合。** 把一张卡片本地化成十几种语言,为每个投放位置生成每种尺寸,在四十场活动中替换一个标识组合 - 全部源自同一个设计,由一张电子表格驱动。
- **属于你自己,离线,私密。** 你的作品留在你的设备上 - 不需要账号,制作或导出资源不需要上传任何内容,也没有许可证需要审计。合上笔记本电脑在飞机上继续工作。(存在两个可选的服务器附加组件,可以完全忽略不用 - 参见[服务器界面](/info/server-surface.html)。)
- **开放,不被锁定。** 引擎是开源的,你的作品存放在普通的 URL 中,而不是某家供应商的数据库里。
- **需要时的超能力。** 你从不*必须*进行设计 - 但一旦你决定动手,上限很高。在 Design 画布上自由排版页面。在 Sequence Studio 的时间轴上剪辑片段、卡片和音乐。用实时指导录制干净的语音和镜头素材。在一个能告诉你比大多数设计软件都多得多的取色器指导下,亲手搭建整套品牌体系。

> **这些约束不是把你关起来 - 而是接住你。** 把这些护栏想象成保龄球道边的缓冲杆:球还是你自己扔的 - 文字、图像、想法都是 - 代码只是让它不至于滚进沟里,从而永远不会破坏品牌规范。你不是在被自动化取代;被拿走的只是那些繁琐的部分:品牌合规检查、每种尺寸的重新导出、逐种语言的手工本地化。留下的是真正需要你判断的事。而*你*编写的工具,正是让公司其余的人无需在每一份素材上都拉上你,就能做出好作品的方式:你的判断力,被规模化了。

## 它与其他产品的比较

Lolly 并不试图成为 Canva 或 Figma。它所处的位置是*规则、可重复性和硬性约束比自由手绘的灵活性更重要*的场景 - 把设计决策转化为团队人人都能用的工具,无需你参与每一份素材。

逐产品的详细对比见带日期标注的[比较页面](/info/compare.html) - Canva、Adobe、Figma、Penpot、品牌门户、渲染 API 和文件转换器 - 让步之处写在前面,后面附有[能力对照表](/info/positioning.html)。

**选用 Lolly** 来处理你反复制作的素材 - 活动指示牌、语录卡片、本地化横幅、电子邮件签名、发货标签、社交媒体变体、数据驱动的图表和地图。**选用设计工具** 来处理量身定制的主视觉、一次性的活动创意,以及那些*本就该*跳出系统框架的构思过程。Lolly 执行系统化流程;它不会取代设计工作室。

## 你能制作什么

### 一切正确,无需等待

填几个字段,拿到成品资源 - 不用挑字体,不用纠结配色,也不用怀疑“这是正确的标志吗?”工具早就知道答案。电子邮件签名、活动倒计时、语录卡片、徽章、街道地图 - 周二下午四点你的团队所需要的一切,自助完成。而且由于没有任何客户数据离开设备,协作没有合规风险。

Street Map 就是这种取舍的一个恰当例子:你选一座城市和几种颜色,制图法、道路粗细和水域颜色都为你决定好了。

![东京的 Street Map 渲染图,近黑背景配霓虹色,由城市下拉菜单和两个取色器生成](/t/url-shot?url=%2F%23%2Ftool%2Fstreet-map%3Fcity%3Dtokyo%26theme%3Ddark%26roadColor%3D22d3ee%26waterColor%3D0e7490%26background%3D0b1021%26full&width=1440&height=900&dpi=96&waitMs=3200&cropSelector=%23tool-canvas&walker=1&format=svg&dark=1&filename=vt-street-map-poster)

### 从实时数据到成品视觉

将一份 **CSV** 或 **JSON** 表格连接到图表、地图或表格模板,更新数字即可 - 版式会自行处理。选举结果、季度财报、天气事件:格式做一次,每次故事更新时重复使用。与你的品牌风格*完全*一致,因为这是在模板层面强制执行的,而不是一条松散的指导原则。

![Chart Creator 直接输出的环形图 - 标签、数值和颜色全部由模板放置,而非手工排布](/t/url-shot?url=%2F%23%2Ftool%2Fchart-creator%3Ffull&width=1440&height=900&dpi=192&waitMs=2500&cropSelector=%23tool-canvas&walker=1&format=svg&dark=1&filename=use-chart-output)

### 工具组合工具

一个工具可以将另一个工具的实时输出作为素材嵌入 - 一张会渲染自己二维码的姓名徽章,一张嵌入实时图表的卡片 - 无需设计工具,也无需手动合成。嵌入的渲染保持实时,加载时重新渲染;它从来不是一张扁平化的静态图片。

### 需要时的前沿功能

高级滤镜、合成、动画、实时摄像头特效、生成式设计 - 模板作者可以使用任何一种 Web 技术,因此上限很高。

![Mesh Gradient 的输出效果 - 一片完全由你品牌调色板令牌构建而成的柔和生成式色彩场](/t/url-shot?url=%2F%23%2Ftool%2Fgradient%3Ffull&width=880&height=560&dpi=96&waitMs=2500&cropSelector=%23tool-canvas&walker=1&format=svg&dark=1&filename=use-mesh-output)

编写*工具*,而非文件:构建能生成一万张卡片的东西,而不是手工做一万张卡片。把不该变的东西锁定;只暴露那些本就该变化的部分。

## 你会注意到的细节

![Growth's default bloom - a dense field of looping brand-coloured lines grown out from a ring, every line a real SVG path](/t/url-shot?url=%2F%23%2Ftool%2Fgrowth%3Ffull&width=880&height=880&dpi=96&waitMs=3000&cropSelector=%23tool-canvas&walker=1&format=svg&dark=1&filename=use-growth-bloom)

- **印刷,做到位。** 真实的物理单位(mm/cm/in/pt)与 DPI、出血和裁切线、CMYK 与 PDF/X-4 输出意图 - 印刷厂拿到的正是它需要的。参见[导出](/info/exporting.html#size-print-units)。
- **视频与动效。** 导出 WebM/MP4(含音轨)、动态 PNG/WebP 和动态 SVG - 都出自制作静态图的同一模板。**Sequence Studio** 更进一步:画布下方是真正的时间线,带有吸附对齐的片段行、自由的叠加轨道、修剪与分割、转场预设、配音录制和音乐混音 - 由确定性合成器渲染为 MP4、WebM、GIF 或 APNG,而非屏幕录制。Lottie 文件可作为动态素材*导入*,并渲染为上述任一格式。片段上方是**关键帧**:在某一瞬间摆好一个方框姿态,用真实的深度把它从页面上抬起,再让摄像机掠过结果。参见[使用 Lolly → 时间线](/info/using.html#timeline-sequence-studio)与[制作动画](/info/animating.html)。
- **音频。** 录制语音备忘并保存为 MP3(或其原生的 M4A/OGG/WebM),全程在本地设备完成 - 还可导入 MP3、WAV、OGG、M4A、FLAC、MIDI 或音轨模块(MOD/XM/IT/…),作为视频下方的配乐或 Neurospicy Mode 中的环境音轨。
- **绘制,而非将就。** Design 工具配有真正的**钢笔**:点击放置锚点,拖动生成曲线,并可选择贯穿这些点的曲线类型。用**联合、减去、相交和排除**组合形状,为描边生成轮廓,偏移剪影,简化路径 - 几何运算基于精确的贝塞尔数学,因此你画出的形状在任何尺寸下都保持清晰,并且从链接或 CLI 渲染出的结果完全一致。参见[使用 Lolly → 绘制自己的形状](/info/using.html#drawing-your-own-shapes-the-pen)。
- **可编辑矢量图。** 支持 SVG、EPS、EMF 和 DXF 导出。矢量输出中文字会转为轮廓路径,因此印刷厂或切割机拿到的是清晰的几何图形,在任何地方都能打开。(轮廓化的文字在 Illustrator 中不再可*重新编辑输入* - 这是为了在没有字体的情况下实现完美保真所做的取舍。)
- **积少成多的便利。** 将一张电子表格批量转换为一整个文件夹的素材;保存会话并归类到 Projects 中;将任意状态分享为一个 URL;把整个文件夹渲染为一个 zip。
- **真正令人愉悦的界面。** 处处可撤销/重做,可关闭的音效层,主题循环切换,实时相机滤镜 - 还有 **Neurospicy Mode**,一个在应用中随你移动、拥有自己停靠栏的后台专注音乐播放器。
- **需要时更沉静的界面。** **Profile → Accessibility** 下的四个开关 - *Reduce motion*(减少动效)、*Hide colourful previews*(隐藏彩色预览)、*High contrast*(高对比度)和 *Large text*(大字体) - 让应用围绕你的工作安静下来。每个开关在你打开之前都处于关闭状态,且都不会触及画布或改变导出结果的任何一个像素。参见[你的个人资料 → 无障碍](/info/profile.html#accessibility)。
