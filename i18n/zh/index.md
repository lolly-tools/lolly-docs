
# Lolly - 落地页文案

你来做，成果归你：几秒钟就得到成品文件，全都在自己的设备上。
选一个工具，填上你的文字，出来就是对的：颜色、字体和排版早已安排好。
该一致的地方分毫不差，该变化的地方随你调整。
免费，而且一直免费：不用账号，不用绑卡，没有附加条件。

## 市场营销

### 一切都已完成，无需等待。

你需要一张语录卡、一个活动图块、一份本地化签名档，今天就要，不是下个迭代。即使你从没打开过设计工具，Lolly 交回来的也是符合品牌规范的成品。规则写在模板里，所以产出自然是对的。

- **填几个字段，拿到成品素材。** 不用挑字体，不用纠结配色，也不用问“这个标志对不对？”工具早已知道。你只管出文字。
- **无穷变体，唯一事实来源。** 把一张语录卡本地化成 12 种语言，在 40 场营销活动中替换品牌组合标志，或为每个投放位生成每一种尺寸变体，全都不用碰设计本身。这一切都能在批量表格里用一份电子表格驱动：粘贴或导入一份 CSV，每一行产出一份成品文件。
- **常规素材不再卡在创意团队。** 邮件签名档、活动倒计时、语录卡、二维码，团队在周二下午 4 点需要的一切，自助即可完成。
- **一张图不必走采购流程。** 不用审批新的订阅，不用审查许可，也不用为周二只需要一张图块的人买一个席位。

你在出差途中，演示文稿出了错，客户提出了具体要求。Lolly 能把任何一台设备变成素材工作室：不需要设计师，不需要等待，没有借口。

- **什么都不用等。** 如果你正在路上，离会议已经没有几天，素材现在就要，那就生成出来。

- **对方开口时，活已经干完了。** 第一次有人需要这份素材时做出来的工具，此后在任何时刻、任何时区，几秒钟就能再做一份。

## 记者

### 为速度与精准而生的编辑工具箱。

一次建好你的资讯编辑风格，此后即可随着实时数据到位，生成达到出版质量的素材。

- **把数据直接带入可视化内容。** 把结构化数据连接到图表、地图与表格模板。更新数字，排版会自行处理。
- **精确匹配你的出版物风格。** 工具在编写时就固化了排版与色彩约束：你的内部风格在模板层面被强制执行，而不只是一条松散的指导原则。
- **印刷就绪或屏幕就绪。** 从同一个模板导出 SVG、CMYK PDF、高分辨率 PNG 或 60fps 视频。一个源头，满足制作部门所需的每一种格式。
- **为重复出现的报道提供可复用版式。** 选举结果、季度财报、天气事件：模板只需构建一次，每次报道时重复使用。

## 运营

### 为日常产出带来工业级的严谨。

并非所有工作都是市场营销。托运标签、批量胸卡、合规单页、事故通知：这类产出中排版承载着含义，数据绝不能出错。Lolly 对待一张托运标签，与对待一张活动海报同样严谨。

- **结构化数据输入，精确输出。** 输入一份 CSV 或 JSON 表格，每个字段都会精确落在模板预期的位置上：每一行产出一份成品文件。
- **物理精度。** 真实单位（mm/cm/in/pt）、真实 DPI、出血线与裁切标记。标签打印机或印刷厂拿到的，正是它需要的东西。
- **逻辑在工具内部运行。** 条形码、日期运算、条件排版、对比度检查：都在渲染时算好，无需手工处理。
- **设计上即具确定性。** 相同的输入，每次都得到相同的文件。可审计、可重复，也可通过 CLI 或流水线自动化。

## 媒体与创意

### 别再做机器更擅长的事。

你设计的是系统、解决的是问题，而不是一次性的稿件。Lolly 是执行层，把你的设计决策变成整个组织都能使用的工具，不必每做一份素材都把你拉进来。

- **上限就是 Web 平台本身。** 高级滤镜、合成、动画、生成式设计：模板作者可以用上每一项 Web 技术，浏览器画得出来的东西，工具就能以生产级质量导出。
- **工具可以组合工具。** 一个工具能把另一个工具的产出当作实时素材嵌进来：一张自己渲染二维码的胸卡，一张放进实时图表的卡片，既不需要设计软件，也不需要手工合成。
- **编写工具，而不是文件。** 与其做 10,000 张社交卡片，不如做一个能生成 10,000 张社交卡片的模板。你的时间花在设计问题上，而不是量产环节。
- **消灭繁琐。** 最佳排版、标志摆放、地图标点定位、色彩对比度检查、导出尺寸：全都在模板层解决。规则你定一次，重复交给机器。
- **该锁的锁住，该放开的放开。** 把品牌约束写死，只暴露真正需要变化的变量。工具本身就成了创意的护栏。

## 开发者

### 你的构建流水线，也该管你的视觉素材。

图片就是构建产物，就该这样对待。Lolly 可以从 CLI 运行，让你用生成其他一切的方式生成素材：可重复、自动化，并且成为工作流的一部分。

- **让模型去画草图，别让它上印刷机。** 靠提示词生成印刷级媒体既昂贵，结果也只是接近，而不是正确。工具每次都产出同一份文件，而且分文不花。
- **产出可复现。** 相同的输入每次都产出相同的文件。提交一个 URL，需要时再生成，不必再把图片提交进仓库，也不必去 Slack 里追最新版本。
- **把媒体文件请出代码库。** 在构建时生成 OG 图、二维码、社交卡片和数据图表，而不是把二进制文件存进 Git。
- **在素材内部执行逻辑。** Code Canvas、Chart Creator 这类工具让你把真实内容放进生产级模板：代码片段、结构化数据、实时数值，都无需自建渲染器。
- **零锁定。** 开源引擎，本地计算，没有 API 密钥，没有速率限制。

```bash
lolly qr-code --url=https://suse.com --output=og-qr.svg
lolly wordmark --text="Ship it." --output=wordmark.png
```

## AI 智能体

### 让你的模型去调用工具，而不是产生幻觉。

一个带参数的 URL 只需几个 token。一份创意简报加上图像生成要花掉数千个，而结果仍达不到印刷级。Lolly 为你的智能体提供一层确定、可复核、可直接投产的创意能力。


- **生产质量不会漂移。** 工具用极小的算力就能产出生产级作品，而且在本地完成。工具是写死的。你的模型偷懒时，排版不会跟着偷懒。排印规则、色值、间距，都属于结构，而不是提示词。
- **规模化地节省 token。** 用一个 URL 生成一张定制活动卡片，成本只是通过生成式模型反复调提示词做出同样产出的零头。
- **让数据各归其位。** 结构化输入对应结构化模板。讲者姓名、场次时间、产品版本，每次都精确落在设计预期的位置上。
- **确定、可审计、可版本控制。** 每一份产出都能由它的输入复现。正式素材中不会出现随机的意外。

```
Use Lolly to invite the team to KubeCon.

Parameters:
  title: "KubeCon 2026"
  date: "2026-11-10"
  location: "Atlanta"

Output the file URL.
```

## 大型企业的 IT 与安全团队

### 创意文件不该成为安全风险。

每当有人为了“把样子弄对”而把文件上传到第三方服务，就等于埋下一次随时会发生的数据外泄。Lolly 从源头消除这个问题：创意生产留在本地，始终由你掌控。

- **数据留在设备上。** 没有云端渲染，没有分析统计，没有遥测，除了用户明确触发的少数几次请求之外，根本不发起任何网络请求，而这几次请求在[隐私政策](/info/privacy.html)中都逐一列明。同事创作的内容留在他们自己的机器上。像 Strip Hidden Data 这样的设备端工具，完全在浏览器内清除图片、SVG 与 PDF 中的 EXIF 和元数据，不上传任何内容。就连给 PDF、整个下载包或分享链接加上密码，也在设备上完成；密码从不离开设备。
- **自托管，实现完全的物理隔离控制。** 部署在你自己的基础设施上；两个可选的服务端组件可以完全不部署。[自主可控的生产](/info/sovereign-production.html)阐明了整体立场，[服务器攻击面](/info/server-surface.html)则是完整清单。
- **缩小供应商暴露面。** 一个开源平台即可取代一大堆用于创意生产的 SaaS 订阅。供应商更少，意味着合同更少、审计更少、被攻破的途径也更少。
- **在基础设施层面执行品牌治理。** 工具编写一次，以数据形式分发，不是文件，也不是人工流程。发出去的东西，正是被批准发出去的东西。
- **让关键信息即刻变成人能读懂的格式。** 事故通报、合规报告、高管简报：结构化数据几秒钟就变成出版质量的产出，不卡在设计环节。
- **公开进行的加固。** Lolly 的密码学与文件解析引擎正在接受 SUSE 的基础设施加固：这套方法论支撑了三十多年面向全球最大型企业的安全技术与服务。Content Credentials 与本地加密在设计上是强健的；在加固完成之前，请在受限范围内试点使用。参见[采用与治理](/info/adoption-governance.html#status)。

## 工具


可以把它想成设计的自动售货机。选一项，出一个结果。次次如此。

工具是一个开箱即用的创意模板，它清楚自己要做什么、怎么做。给它一个标题、一个日期、一个数字，它就产出一份合乎规范的成品素材。

无需设计经验。不用决定字体、颜色或间距，工具早已知道怎样最好。无论你是设计师、市场人员、开发者还是 AI 智能体，产出都是一样的。

工具由懂品牌的人编写一次，此后由其他所有人使用：在网页浏览器里、在手机上、在命令行里，或在自动化流水线中。设计决策在模板层面就已锁定，剩下要做的只有填入内容。
