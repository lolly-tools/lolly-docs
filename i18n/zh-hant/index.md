
# Lolly - 首頁文案

你做的東西，就是你的：幾秒鐘產出成品檔案，全都在自己的裝置上。
挑一個工具，填上你的文字，成品就是對的：色彩、字體與版面都已經設定好。
該一致的地方一致，該不同的地方隨你不同。
免費，而且會一直免費：不用帳號、不用信用卡、沒有附帶條件。

## 行銷人員

### 全部做好，不用等。

你需要一張語錄卡、一張活動圖、一份在地化的簽名檔 - 今天就要，不是等下個衝刺週期。就算你從沒開過設計軟體，Lolly 交回來的也是完成、且符合品牌規範的成品。規則寫在範本裡，所以產出就是對的。

- **填幾個欄位，拿到完成的素材。** 不用挑字體、不用猶豫色彩、不用問「這是正確的標誌嗎？」工具已經知道了。你只要負責文字。
- **無限多種變化，單一事實來源。** 把一張語錄卡在地化成 12 種語言、在 40 檔行銷活動中替換品牌組合標誌，或為每個版位做出每種尺寸的變體 - 完全不用動到設計。全部用批次表格裡的試算表驅動：貼上或匯入 CSV，每一列產出一個完成檔案。
- **例行素材不必卡在創意團隊。** 電子郵件簽名檔、活動倒數、語錄卡、QR code - 你的團隊在週二下午四點需要的東西，自己就能做。
- **不用為了一張圖走採購流程。** 不用批准新的訂閱、不用稽核授權，也不用為了週二只需要一張圖的人多買一個席次。

## 業務

### 每一場會議，都帶著剛好需要的東西進門。

你人在外地，簡報內容不對，客戶又指名要某個東西。Lolly 讓任何裝置都變成素材工作室 - 不用設計師、不用等、沒有藉口。

- **什麼都不用等。** 你人在路上，離會議已經沒有時間可耗，素材現在就要。那就生出來。
- **修好你手上那份簡報。** 把 PowerPoint 丟進 Lolly，投影片立刻打開，你可以挑出值得留下的部分，當成銳利的向量圖再利用 - 然後用幾行 Markdown 重建整份簡報，回寄一份原生、可編輯的 `.pptx`。
- **一個人，就能做完一整檔活動。** 每個地區的每一位業務，依循同一套規則，做出同樣的完成度。
- **世界級的體驗。** 就算是瞬間算圖出來的，也不會看起來像趕出來的。沒有任何東西是一次性的 - 所以每一次互動都比上一次更精緻一點。
- **他們開口時，工作早就做完了。** 第一次有人需要這個素材時所建立的工具，之後在任何時間、任何時區，都能在幾秒內再做一次。

## 新聞工作者

### 你的編輯工具組，為速度與精準而生。

把你的資訊圖表編輯風格建立一次，之後就能在事件發生的當下，用即時資料產出可供刊登品質的素材。

- **把資料直接帶進視覺。** 將結構化資料接上圖表、地圖與表格範本。更新數字，版面自己會處理好。
- **精準符合你的刊物風格。** 工具在製作時就把字體排印與色彩限制寫死 - 你的內部風格規範在範本層級被強制執行，而不是一份鬆散的建議。
- **可付印，也可上螢幕。** 從同一份範本輸出 SVG、CMYK PDF、高解析度 PNG 或 60fps 影片。單一來源，涵蓋製作部門需要的每一種格式。
- **重複性報導可重複使用的版式。** 選舉結果、季度財報、天氣事件 - 範本做一次，每次題材再出現時就再用一次。

## 營運

### 用工業級的嚴謹，處理日常產出。

不是每件事都跟行銷有關。託運標籤、識別證批次、法遵單頁文件、事故通知 - 這些產出的版面本身就承載意義，資料也不容出錯。Lolly 處理一張託運標籤的嚴謹程度，和處理一張行銷海報一樣。

- **結構化資料進，精確產出。** 餵進一份 CSV 或 JSON 表格，每個欄位都會落在範本預期的位置 - 每一列產出一個完成檔案。
- **實體尺寸精準。** 真實單位（mm/cm/in/pt）、真正的 DPI、出血與裁切標記。標籤印表機或印刷廠拿到的，正是它們需要的。
- **邏輯在工具裡執行。** 條碼、日期運算、條件式版面、對比度檢查 - 都在算圖當下計算，不用人工處理。
- **設計上就是可決定性的。** 相同輸入，每次都得到相同檔案。可稽核、可重現，也能從 CLI 或流水線自動執行。

## 媒體與創意工作者

### 別再做機器最擅長的事。

你設計的是系統、解決的是問題，不是一次性的作品。Lolly 是把你的設計決策變成工具的執行層，讓整個組織都能使用 - 不必每做一個素材都找你。

- **天花板就是網頁平台本身。** 進階濾鏡、合成、動畫、生成式設計：範本作者可以用上每一項網頁技術，而瀏覽器畫得出來的東西，工具都能以正式產出品質輸出。
- **工具可以組合工具。** 一個工具能把另一個工具的產出當成即時素材嵌進來 - 一張自己算出 QR code 的名牌、一張放進即時圖表的卡片 - 不需要設計軟體，也不用手動合成。
- **做工具，不是做檔案。** 建一個能產出 10,000 張社群圖卡的範本，而不是手做 10,000 張社群圖卡。你的時間花在設計問題上，不是花在量產。
- **消滅瑣事。** 最佳排版、標誌位置、地圖標記定位、色彩對比檢查、輸出尺寸 - 全部在範本層解決。規則你定一次，重複的部分交給機器。
- **該鎖的鎖住，該放的放開。** 把品牌限制寫死。只開放真正應該變動的變數。工具本身就成了創意的護欄。

## 開發人員

### 你的建置流程也該包含視覺素材。

圖片就是建置產物，請這樣看待它們。Lolly 可以從 CLI 執行，所以你能用產生其他東西的同一套方式產生素材 - 可重現、自動化，而且是工作流程的一部分。

- **讓模型畫草稿，別讓它上印刷機。** 用提示詞生出可付印品質的媒體既昂貴，結果也只是接近，而不是正確。工具每次都做出同一個檔案，而且不用花錢。
- **可重現的產出。** 相同輸入每次都產生相同檔案。把一個 URL 提交進版控，需要時再重新產生 - 不必再把圖片簽入儲存庫，也不必在 Slack 上追最新版本。
- **把媒體檔案移出程式碼庫。** 在建置時產生 OG 圖片、QR code、社群圖卡與資料視覺化，而不是把二進位檔存進 Git。
- **在素材內部執行邏輯。** Code Canvas 與 Chart Creator 這類工具，讓你把真實內容 - 程式碼片段、結構化資料、即時數值 - 放進正式品質的範本，不必自己寫一套算圖器。
- **零綁定。** 開源引擎、本機運算、不用 API 金鑰、沒有速率限制。

```bash
lolly qr-code --url=https://suse.com --output=og-qr.svg
lolly wordmark --text="Ship it." --output=wordmark.png
```

## AI 代理

### 叫你的模型去用工具，不是去產生幻覺。

一個帶參數的 URL 只要幾個 token。一份創意需求說明加上圖像生成則要好幾千個 - 而且結果仍然達不到可付印品質。Lolly 為你的代理提供一個具決定性、可審查的創意層，隨時能投入正式產出。


- **正式產出品質不會走樣。** 工具只用一小部分的運算量就能產出正式品質的作品 - 而且在本機完成。工具是寫死的。就算你的模型偷懶，版面也不會。字體排印規則、色彩數值、間距 - 這些是結構，不是靠提示詞得來的。
- **大規模節省 token。** 用一個 URL 產生客製化活動圖卡的成本，只是透過生成式模型調校提示詞做出同樣結果的一小部分。
- **把資料放在該放的位置。** 結構化的輸入對應到結構化的範本。講者姓名、場次時間、產品版本 - 每次都精準落在設計預期的位置。
- **可決定、可稽核、可版本控管。** 每一份產出都能從它的輸入重現。正式素材裡不會有隨機的意外。

```
Use Lolly to invite the team to KubeCon.

Parameters:
  title: "KubeCon 2026"
  date: "2026-11-10"
  location: "Atlanta"

Output the file URL.
```

## 大型企業的 IT 與資安團隊

### 創意檔案不該成為資安風險。

每次有人為了「讓它看起來對一點」而把檔案上傳到第三方服務，就是一起隨時可能發生的資料外洩事件。Lolly 從源頭消除這個問題 - 創意製作留在自有環境，在你的掌控之下。

- **資料留在裝置上。** 沒有雲端算圖、沒有分析、沒有遙測 - 除了使用者明確觸發的少數幾個之外，完全沒有網路請求，而且每一個都列在[隱私權政策](/info/privacy.html)裡。同事做出來的東西，留在他們自己的機器上。像 Strip Hidden Data 這類在裝置端執行的工具，完全在瀏覽器內清除圖片、SVG 與 PDF 的 EXIF 與中繼資料 - 什麼都不會上傳。就連為 PDF、整份下載或分享連結設密碼鎖定，也都在裝置端完成；密碼永遠不會離開裝置。
- **自行架設，取得完全的離線隔離控制。** 部署在你自己的基礎架構上；兩個選用的伺服器元件可以完全不裝。[自主產出](/info/sovereign-production.html)說明了完整立場，[伺服器暴露面](/info/server-surface.html)則是完整清單。
- **縮小供應商暴露面。** 一個開源平台，取代創意製作上一大堆零散的 SaaS 訂閱。供應商越少，合約越少、稽核越少、可被入侵的途徑也越少。
- **在基礎架構層級落實品牌治理。** 工具製作一次，以資料形式散布 - 不是檔案，也不是人工流程。送出去的東西，正是當初核准可以送出去的東西。
- **立刻把關鍵資訊轉成人看得懂的格式。** 事故通報、法遵報告、高階主管簡報 - 結構化資料在幾秒內變成可刊登品質的產出，不會卡在設計環節。
- **公開進行的強化。** Lolly 的密碼學與檔案解析引擎正在接受 SUSE 的基礎架構強化：那是三十多年來為全球最大型企業提供資安技術與服務所累積的紀律。Content Credentials 與本機加密在設計上就很強韌；在強化完成之前，請在限定範圍內試行。請見[採用與治理](/info/adoption-governance.html#status)。

## 工具


把它想成設計版的自動販賣機。選一個，就拿到結果。每次都是。

工具就是一份可以直接用的創意範本，清楚知道自己在做什麼、要怎麼做。給它一句標題、一個日期、一個數字 - 它就會照規格產出完成的素材。

不需要設計經驗。不用決定字體、色彩或間距 - 工具最清楚。不管你是設計師、行銷人員、開發人員還是 AI 代理，產出都一樣。

工具由懂品牌的人製作一次，之後就給所有人使用 - 從網頁瀏覽器、手機、命令列或自動化流水線都行。設計決策在範本層級就已經鎖定。剩下要做的，只有填內容。
