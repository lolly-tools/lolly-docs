# 給創作者的 Lolly

你想快速做出好東西,而且要做對。Lolly 正是為此而生:填幾個欄位,就能得到一份完稿檔案 - 版面、字型、規則都由工具強制執行,而非全靠你的眼力(除非你想自己動手 - 那你手邊就有一整套強大的媒體工具)。不需要設計軟體,不必等待。它在你自己的裝置上執行,離線也能用。

**對你的好處:** 你能在幾分鐘內交付成品,看起來卻像花了好幾個小時完成。你永遠不必苦等設計師,而且因為品牌規則已內建其中,不合品牌調性的成品絕不會掛上你的名字。你只會顯得快速、精緻又可靠。

本頁面會告訴你充分運用 Lolly 所需知道的一切。

> **你是接力賽中的一棒。** 你所編寫的工具不會止步於你手上 - 開發者可以把它們串接進自動化流程([Lolly for Builders](/info/builders.html)),非設計背景的同事也能自助執行,不必經過你就能拿到一份完稿、合乎品牌規範的檔案。想看整個生命週期如何層層疊加效益,請見[The lifecycle of a campaign](/info/overview.html#the-lifecycle-of-a-campaign)。

## 為什麼選 Lolly - 你的優勢

- **完稿,而非瑣碎調整。** 工具早已知道字型、色彩、標誌、間距。你只要提供文字內容;它就回給你成品資產。沒有什麼需要你再三斟酌。
- **從結構上就正確。** 設計規則、版面限制與運作邏輯都內建於範本之中 - 除非工具作者刻意留出開放空間,否則輸出結果不會偏離規格。在守得住的護欄之內,擁有天馬行空的創作空間。
- **一份來源,任何格式。** 同一份設計可匯出為 SVG、可印刷的 PDF、高解析度 PNG,或 60fps 影片。做一次,到處都能用。
- **無限排列組合。** 把一張卡片在地化成十幾種語言、為每個投放位置產出每一種尺寸、在四十個活動中替換一個標誌組合 - 全都出自同一份設計,由一份試算表驅動。
- **屬於你,離線,且私密。** 你的作品留在你的裝置上 - 不需要帳號,製作或匯出資產都不必上傳任何內容,也沒有授權需要稽核。在飛機上闔上筆電蓋,照樣能繼續工作。(另有兩個選用的伺服器附加元件,完全可以忽略不用 - 詳見[Server Surface](/info/server-surface.html)。)
- **開放,不被綁定。** 引擎是開放原始碼,你的作品存放在一般的 URL 上,而不是鎖在某家供應商的資料庫裡。
- **想要時就擁有超能力。** 你永遠不*必須*動手設計 - 但一旦你決定要做,上限就很高。在 Design 畫布上自由排版頁面。在 Sequence Studio 的時間軸上剪輯片段、卡片與音樂。搭配即時指導,錄下乾淨的人聲與鏡頭。在色彩選取器的指引下,親自建立整套品牌 - 這個選取器告訴你關於一個顏色的資訊,遠比多數設計套件所能提供的還要多。

> **限制不是牢籠 - 它們是承接你的網。** 把這些護欄想成保齡球道旁的緩衝欄:你依然親自把球丟出去 - 文字、圖像、想法都由你決定 - 程式碼只是讓球不掉進溝裡,讓品牌調性永遠不會被破壞。你並不是被自動化取代;被拿掉的是繁瑣的部分:品牌審查、每種尺寸重新匯出、逐一手動在地化成十幾種語言。留下來的,是真正需要你判斷的那個決定。而你所編寫的工具,正是讓公司其他人能做出好作品、卻不必把你拉進每一份資產製作過程的關鍵:你的判斷力,得以規模化。

## 與其他工具比較

Lolly 並不打算成為 Canva 或 Figma。它的定位在於*規則、可重複性與嚴格限制比自由手繪彈性更重要*的場合 - 把設計決策轉化為整個團隊都能使用的工具,不必每份資產都拉你進來。

逐一產品的詳細比較列在附有日期的[比較頁面](/info/compare.html) - Canva、Adobe、Figma、Penpot、品牌入口網站、算繪 API 與檔案轉換工具 - 讓步之處寫在最前面,後面附上一份[能力對照表](/info/positioning.html)。

**選擇 Lolly**,用於你一再重複製作的資產 - 活動看板、名言卡片、在地化橫幅、電子郵件簽名檔、出貨標籤、社群版本、資料驅動的圖表與地圖。**選擇設計工具**,用於量身打造的主視覺、一次性的活動概念、以及*本就該*跳脫系統框架的發想過程。Lolly 執行既定系統;它不會取代設計工作室。

## 你能做出什麼

### 一切正確,不必久等

填幾個欄位,就能拿到完稿資產 - 不必挑字型,不必猶豫用色,也不用問「這是正確的標誌嗎?」工具早已知道答案。電子郵件簽名檔、活動倒數計時、名言卡片、識別證、街道地圖 - 週二下午四點你團隊所需的一切,都能自助完成。而且因為沒有客戶資料離開裝置,協作也沒有合規風險。

Street Map 就是這種取捨的一個公道範例:你選一座城市和幾個顏色,製圖方式、道路粗細與水域都已替你決定好。

![Street Map 在近黑背景上以霓虹色算繪出的東京,由城市下拉選單與兩個色彩選取器產生](/t/url-shot?url=%2F%23%2Ftool%2Fstreet-map%3Fcity%3Dtokyo%26theme%3Ddark%26roadColor%3D22d3ee%26waterColor%3D0e7490%26background%3D0b1021%26full&width=1440&height=900&dpi=96&waitMs=3200&cropSelector=%23tool-canvas&walker=1&format=svg&dark=1&filename=vt-street-map-poster)

### 從即時資料到完稿視覺

把一份 **CSV** 或 **JSON** 表格連接到圖表、地圖或表格範本,更新數字即可 - 版面會自行處理妥當。選舉結果、季度營收、天氣事件:格式只需建立一次,每次報導都能重複使用。與你的公司風格*完全*吻合,因為規則是在範本層級強制執行的,而不是留作鬆散的參考準則。

![直接出自 Chart Creator 的甜甜圈圖 - 標籤、數值與色彩都由範本安排,而非手動放置](/t/url-shot?url=%2F%23%2Ftool%2Fchart-creator%3Ffull&width=1440&height=900&dpi=192&waitMs=2500&cropSelector=%23tool-canvas&walker=1&format=svg&dark=1&filename=use-chart-output)

### 工具組合工具

一個工具可以將另一個工具的即時輸出當作資產嵌入其中 - 例如一張能算繪自己 QR code 的姓名識別證,或一張嵌入即時圖表的卡片 - 不需要設計工具,也不需要手動合成。嵌入的算繪內容會保持即時,並在載入時重新算繪;它從來不是一張已定版的靜態圖片。

### 需要時,前沿功能就在那裡

進階濾鏡、合成、動畫、即時鏡頭效果、生成式設計 - 每一項網頁技術都能供範本作者使用,因此上限很高。

![Mesh Gradient 的輸出結果 - 一個完全由你品牌調色盤 token 構成的柔和色彩生成場域](/t/url-shot?url=%2F%23%2Ftool%2Fgradient%3Ffull&width=880&height=560&dpi=96&waitMs=2500&cropSelector=%23tool-canvas&walker=1&format=svg&dark=1&filename=use-mesh-output)

編寫*工具*,而非檔案:打造能產生一萬張卡片的東西,而不是親手做出一萬張卡片。鎖定不該變動的部分;只開放真正應該變動的部分。

## 你會注意到的細節

![Growth's default bloom - a dense field of looping brand-coloured lines grown out from a ring, every line a real SVG path](/t/url-shot?url=%2F%23%2Ftool%2Fgrowth%3Ffull&width=880&height=880&dpi=96&waitMs=3000&cropSelector=%23tool-canvas&walker=1&format=svg&dark=1&filename=use-growth-bloom)

- **列印，做得恰到好處。** 真實的實體單位（mm/cm/in/pt）與 DPI、出血與裁切標記、CMYK 與 PDF/X-4 輸出意圖 - 印刷廠能拿到完全符合需求的檔案。詳見[匯出](/info/exporting.html#size-print-units)。
- **影片與動態效果。** 匯出 WebM/MP4（含音軌）、動態 PNG/WebP 與動態 SVG - 全都出自製作靜態圖的同一個範本。**Sequence Studio** 更進一步：畫布下方有一條真正的時間軸，具有磁吸式的片段列、自由的疊加軌道、修剪與分割、轉場預設、旁白錄音與混音功能 - 由確定性的合成器輸出成 MP4、WebM、GIF 或 APNG，而非螢幕錄影。Lottie 檔案可作為動態素材*匯入*，並輸出成上述任一格式。片段上方是**關鍵影格**：在某一瞬間擺好一個方框姿勢、以真實深度將它從頁面上抬起，並讓攝影機掠過成果。詳見[使用 Lolly → 時間軸](/info/using.html#timeline-sequence-studio)與[製作動畫](/info/animating.html)。
- **音訊。** 錄製語音備忘錄並存成 MP3（或其原生格式 M4A/OGG/WebM），全程在裝置上完成 - 也可以匯入 MP3、WAV、OGG、M4A、FLAC、MIDI 或 tracker 模組（MOD/XM/IT/…）作為影片的配樂，或作為 Neurospicy Mode 中的環境音軌。
- **繪圖，不將就。** Design 工具內建真正的**筆刀工具**：點擊放置節點、拖曳產生曲線，並選擇通過這些節點的曲線類型。以**聯集、差集、交集與排除**組合形狀、將線條轉成外框、位移輪廓、簡化路徑 - 幾何運算採精確的貝茲曲線數學，因此你畫的形狀無論放大到多少都保持銳利，且從連結或 CLI 算繪時結果完全一致。詳見[使用 Lolly → 繪製自己的形狀](/info/using.html#drawing-your-own-shapes-the-pen)。
- **可編輯的向量圖。** 支援 SVG、EPS、EMF 與 DXF 匯出。向量輸出中的文字會轉成外框路徑，讓印刷廠或裁切機取得清晰的幾何圖形，且能在任何地方開啟。（外框化的文字在 Illustrator 中不再能*重新編輯打字* - 這是換取無需字型也能完美還原的代價。）
- **累積起來的便利。** 將試算表批次轉成一整個資料夾的素材；儲存工作階段並整理成專案；將任何狀態分享成一個網址；把整個資料夾算繪成單一 zip 檔。
- **真正令人愉快的介面。** 隨處可用的復原/取消復原、可關閉的音效層、主題循環切換、即時相機濾鏡 - 還有 **Neurospicy Mode**，一個在自己的停靠列中跟著你穿梭整個應用程式的背景專注音樂播放器。
- **需要時可以更沉靜的介面。** **Profile → Accessibility** 下有四個開關 - *Reduce motion*、*Hide colourful previews*、*High contrast* 與 *Large text* - 讓應用程式安靜下來配合你的工作。每一項在你開啟之前都是關閉的，而且都不會影響你的畫布，也不會動到匯出結果的任何一個像素。詳見[你的個人檔案 → 無障礙功能](/info/profile.html#accessibility)。

## 充分發揮它的效益

- **[快速入門](/info/quickstart.html)** - 匯入品牌，產出第一個檔案。
- **[Brand Studio](/info/brand-studio.html)** - 打造你的標誌、色彩、字體與設計權杖（`#/start`）。
- **[使用 Lolly](/info/using.html)** - 畫布、控制項、儲存、專案與手機使用方式。
- **[你的個人檔案](/info/profile.html)** - 工具會預先帶入的個人資料，以及如何在裝置之間攜帶這些資料。
- **[匯入設計](/info/design-import.html)** - 帶入你的 Figma / Penpot / Illustrator / InDesign 作品，以及你的 PowerPoint 簡報 - 在裝置上編輯或重新套用品牌。
- **[共同協作](/info/collaborate.html)** - 兩個人即時編輯同一個工作階段，裝置對裝置，不需要帳號，中間也沒有伺服器。
- **[搜尋](/info/search.html)** - 位於 Gallery、Utilities、Projects、Catalogue、Dashboard 與 Profile 底部的單一欄位，能找到你的工具、已儲存的作品、目錄與設定。
- **[Ask Lolly](/info/using.html#ask-lolly)**（`#/ask`）- 輸入問題，即可逐字取得這些指南中相符的段落，並附上直接連結。
- **The Dashboard**（`#/d`）- 儀表板：唯讀顯示你的設計系統、完整的功能地圖、這台裝置能做什麼，以及活動與儲存空間的概覽。
- **[你的最愛](/info/favourites.html)** - 為常用項目加星號，它就會在網格上方擁有自己的方塊。
- **[匯出與格式](/info/exporting.html)** - 所有格式、列印單位、影片與批次處理。
