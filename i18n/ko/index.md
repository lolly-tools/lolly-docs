
# Lolly - 랜딩 페이지 문구

직접 만들고, 그대로 소유하세요. 완성된 파일이 몇 초 만에, 내 기기에서 나와요.
도구를 고르고 문구만 넣으면 제대로 나와요. 색상과 서체, 레이아웃은 이미 정리돼 있어요.
같아야 할 곳은 똑같이, 달라야 할 곳은 원하는 대로.
무료이고, 앞으로도 무료예요. 계정도, 카드도, 숨은 조건도 없어요.


---

## 마케터

### 기다림 없이, 완성된 결과물.

인용 카드, 이벤트 타일, 현지화된 서명이 다음 스프린트가 아니라 오늘 필요하잖아요. Lolly는 디자인 도구를 한 번도 열어본 적이 없어도 브랜드에 맞는 완성본을 바로 돌려줘요. 규칙이 템플릿 안에 들어 있어서 결과물이 제대로 나와요.

- **몇 개 항목만 채우면 완성된 에셋이 나와요.** 서체를 고를 일도, 색상을 두고 고민할 일도, "이게 맞는 로고인가?" 싶을 일도 없어요. 도구가 이미 알고 있어요. 문구만 가져오세요.
- **변형은 무한하게, 기준은 하나로.** 인용 카드를 12개 언어로 현지화하고, 브랜드 로크업을 40개 캠페인에 걸쳐 교체하고, 모든 게재 위치에 맞는 크기 변형을 전부 만들어도 디자인은 건드리지 않아요. 배치 그리드의 스프레드시트로 전부 처리하세요. CSV를 붙여넣거나 가져오면 행마다 완성된 파일이 하나씩 나와요.
- **일상적인 에셋에 크리에이티브 에이전시 병목이 없어요.** 이메일 서명, 이벤트 카운트다운, 인용 카드, QR 코드처럼 화요일 오후 4시에 팀이 필요로 하는 건 전부 직접 만들 수 있어요.
- **그림 한 장 때문에 구매 절차를 밟지 않아요.** 새로 승인받을 구독도, 감사할 라이선스도, 화요일에 타일 하나가 필요했던 사람을 위해 사야 할 좌석도 없어요.

---

## 영업

### 필요한 것을 정확히 갖추고 모든 미팅에 들어가세요.

출장 중인데 자료가 맞지 않고, 고객은 특정한 것을 요청했어요. Lolly는 어떤 기기든 에셋 스튜디오로 바꿔줘요. 디자이너도, 대기 시간도, 변명도 필요 없어요.

- **아무것도 기다리지 마세요.** 출장 중이고, 미팅까지 남은 날이 없고, 지금 에셋이 필요하다면 바로 만들어내세요.
- **이미 가진 자료를 고치세요.** PowerPoint를 Lolly에 올리면 슬라이드가 곧바로 열려서, 남길 만한 것을 골라 선명한 벡터 아트로 다시 쓸 수 있어요. 그런 다음 Markdown 몇 줄로 자료를 다시 구성해 편집 가능한 네이티브 `.pptx`로 돌려보내세요.
- **한 사람이 캠페인 전체를.** 모든 지역의 모든 담당자가 같은 규칙으로, 같은 완성도로 작업해요.
- **세계적인 수준의 경험.** 즉시 렌더링됐는데도 급하게 만든 티가 나지 않아요. 일회성으로 끝나는 것이 없어서, 매번 지난번보다 조금씩 더 다듬어져요.
- **요청이 오는 순간 이미 끝나 있어요.** 누군가 이 에셋을 처음 필요로 했을 때 만들어 둔 도구가, 어느 시간대 몇 시든 몇 초 만에 다시 만들어줘요.

## 기자

### 속도와 정밀함을 위한 편집 툴킷.

인포·에디토리얼 스타일을 한 번 만들어 두면, 사건이 벌어지는 대로 실시간 데이터에서 지면 품질의 에셋을 만들어낼 수 있어요.

- **데이터를 그래픽에 바로 연결하세요.** 구조화된 데이터를 차트, 지도, 표 템플릿에 연결하세요. 숫자만 갱신하면 레이아웃은 알아서 맞춰져요.
- **매체의 스타일을 정확히 맞춰요.** 도구는 타이포그래피와 색상 제약을 코드에 고정한 채로 작성돼요. 느슨한 가이드라인이 아니라 템플릿 차원에서 강제되는 자체 스타일이에요.
- **인쇄용도, 화면용도.** 같은 템플릿에서 SVG, CMYK PDF, 고해상도 PNG, 60fps 영상을 내보내세요. 하나의 원본으로 제작 데스크가 필요로 하는 모든 형식을 만들어요.
- **반복되는 기사를 위한 재사용 포맷.** 선거 결과, 분기 실적, 기상 이벤트처럼 템플릿을 한 번 만들어 두면 그 기사가 나올 때마다 다시 쓸 수 있어요.

## 운영

### 일상적인 산출물에 산업 수준의 엄밀함을.

모든 것이 마케팅은 아니에요. 배송 라벨, 명찰 대량 출력, 컴플라이언스 한 장 요약, 사고 공지처럼 레이아웃이 의미를 담고 데이터가 틀려서는 안 되는 산출물이 있어요. Lolly는 배송 라벨을 캠페인 포스터와 똑같은 엄밀함으로 다뤄요.

- **구조화된 데이터를 넣으면 정확한 결과가 나와요.** CSV나 JSON 표를 넣으면 모든 필드가 템플릿이 기대하는 자리에 정확히 들어가요. 행마다 완성된 파일이 하나씩 나와요.
- **물리적 정밀도.** 실제 단위(mm/cm/in/pt), 정확한 DPI, 재단 여백과 재단선까지. 라벨 프린터나 인쇄소가 필요로 하는 것을 그대로 받아요.
- **로직이 도구 안에서 돌아가요.** 바코드, 날짜 계산, 조건부 레이아웃, 대비 검사는 손이 아니라 렌더링 시점에 계산돼요.
- **설계부터 결정론적이에요.** 같은 입력이면 언제나 같은 파일이 나와요. 감사할 수 있고, 반복할 수 있고, CLI나 파이프라인에서 자동화할 수 있어요.

## 미디어 & 크리에이티브

### 기계가 더 잘하는 일은 기계에 맡기세요.

여러분은 일회성 결과물이 아니라 시스템을 설계하고 문제를 풀잖아요. Lolly는 여러분의 디자인 결정을 조직 전체가 쓸 수 있는 도구로 바꿔주는 실행 계층이에요. 에셋 하나하나마다 여러분이 끼어들 필요가 없어요.

- **한계는 웹 플랫폼 자체예요.** 고급 필터, 합성, 애니메이션, 제너레이티브 디자인까지 모든 웹 기술을 템플릿 작성자가 쓸 수 있어요. 브라우저가 그릴 수 있는 것이라면 도구가 제작 품질로 내보낼 수 있어요.
- **도구가 도구를 조합해요.** 한 도구가 다른 도구의 결과물을 살아 있는 에셋으로 품을 수 있어요. 자기 QR 코드를 직접 렌더링하는 명찰, 실시간 차트를 넣는 카드처럼요. 디자인 도구도, 수작업 합성도 필요 없어요.
- **파일이 아니라 도구를 만드세요.** 소셜 카드 1만 장을 만드는 대신, 1만 장을 만들어내는 템플릿을 만드세요. 시간은 제작 작업이 아니라 디자인 문제에 쓰이게 돼요.
- **지루한 작업을 없애세요.** 최적의 조판, 로고 배치, 지도 핀 위치, 색상 대비 검사, 내보내기 크기까지 모두 템플릿 계층에서 해결돼요. 규칙은 한 번만 정하고, 반복은 기계에 맡기세요.
- **바뀌면 안 되는 것은 잠그고, 바뀌어야 하는 것은 열어두세요.** 브랜드 제약은 코드에 고정하세요. 실제로 달라져야 하는 변수만 노출하세요. 그러면 도구 자체가 크리에이티브 가드레일이 돼요.

## 개발자

### 빌드 파이프라인에 비주얼도 들어가야 해요.

이미지는 빌드 산출물이에요. 그렇게 다루세요. Lolly는 CLI에서 실행되니, 다른 모든 것을 만들 때와 똑같이 반복 가능하게, 자동으로, 워크플로의 일부로 에셋을 만들 수 있어요.

- **모델은 스케치에 쓰고, 인쇄기에는 쓰지 마세요.** 프롬프트로 인쇄 품질의 미디어를 만드는 건 비용이 크고, 정확하기보다는 비슷한 수준에 그쳐요. 도구는 매번 같은 파일을 비용 없이 만들어줘요.
- **재현 가능한 결과물.** 같은 입력이면 언제나 같은 파일이 나와요. URL을 커밋해 두고 필요할 때 다시 만드세요. 이미지를 저장소에 넣거나 Slack에서 최신 버전을 찾아다닐 일이 없어요.
- **미디어를 코드베이스에서 빼내세요.** 바이너리를 Git에 저장하는 대신 OG 이미지, QR 코드, 소셜 카드, 데이터 시각화를 빌드 시점에 만드세요.
- **에셋 안에서 로직을 실행하세요.** Code Canvas나 Chart Creator 같은 도구를 쓰면 코드 조각, 구조화된 데이터, 실시간 값 같은 실제 콘텐츠를 별도 렌더러를 만들지 않고도 제작 품질의 템플릿 안에 넣을 수 있어요.
- **종속은 전혀 없어요.** 오픈 소스 엔진, 로컬 연산, API 키 없음, 요청 한도 없음.

```bash
lolly qr-code --url=https://suse.com --output=og-qr.svg
lolly wordmark --text="Ship it." --output=wordmark.png
```

## AI 에이전트

### 모델에게 환각 대신 도구를 쓰라고 하세요.

매개변수가 붙은 URL은 토큰 몇 개예요. 크리에이티브 브리프에 이미지 생성까지 더하면 수천 개인데, 결과물은 여전히 인쇄 품질이 아니에요. Lolly는 에이전트에게 결정론적이고 검토 가능한, 바로 제작에 쓸 수 있는 크리에이티브 계층을 줘요.


- **제작 품질이 흔들리지 않아요.** 도구는 훨씬 적은 연산으로 제작 품질의 아트워크를 만들고, 그것도 로컬에서 처리해요. 도구는 코드에 고정돼 있어요. 모델이 게을러져도 레이아웃은 그러지 않아요. 타이포그래피 규칙, 색상 값, 간격은 프롬프트가 아니라 구조로 정해져 있어요.
- **규모가 커질수록 토큰을 아껴요.** URL로 맞춤 이벤트 카드를 만드는 비용은 생성 모델에 프롬프트로 같은 결과를 얻어내는 비용의 아주 일부예요.
- **데이터를 제자리에 넣으세요.** 구조화된 입력이 구조화된 템플릿에 대응돼요. 연사 이름, 세션 시간, 제품 버전이 매번 디자인이 기대하는 자리에 정확히 들어가요.
- **결정론적이고, 감사 가능하며, 버전 관리돼요.** 모든 결과물은 입력으로부터 재현할 수 있어요. 제작용 에셋에 확률적인 돌발 상황은 없어요.

```
Use Lolly to invite the team to KubeCon.

Parameters:
  title: "KubeCon 2026"
  date: "2026-11-10"
  location: "Atlanta"

Output the file URL.
```

## 대기업 IT·보안팀

### 크리에이티브 파일이 보안 위험이 되어서는 안 돼요.

누군가 "모양만 좀 다듬으려고" 서드파티 서비스에 파일을 올릴 때마다, 그건 언제 터져도 이상하지 않은 데이터 유출 사건이에요. Lolly는 문제를 근원에서 없애요. 크리에이티브 제작이 온프레미스에서, 여러분의 통제 아래 이뤄져요.

- **데이터는 기기에 남아요.** 클라우드 렌더링도, 분석도, 텔레메트리도 없어요. 사용자가 명시적으로 일으키는 몇 안 되는 요청 외에는 네트워크 요청 자체가 없고, 그 하나하나가 [개인정보 처리방침](/info/privacy.html)에 명시돼 있어요. 동료가 만든 것은 그 사람의 기기에 남아요. Strip Hidden Data 같은 온디바이스 유틸리티는 이미지, SVG, PDF에서 EXIF와 메타데이터를 전부 브라우저 안에서 지워요. 아무것도 업로드되지 않아요. PDF나 다운로드 전체, 공유 링크에 비밀번호를 거는 것도 기기에서 이뤄지고, 비밀번호는 기기를 벗어나지 않아요.
- **완전한 망 분리를 원한다면 직접 호스팅하세요.** 자체 인프라에 배포하고, 선택 사항인 두 서버 구성 요소는 아예 빼도 돼요. [주권적 제작](/info/sovereign-production.html)에 전체 방침이, [서버 노출 범위](/info/server-surface.html)에 전체 목록이 정리돼 있어요.
- **공급업체 접점을 줄이세요.** 오픈 소스 플랫폼 하나가 크리에이티브 제작에 흩어져 있던 SaaS 구독을 대체해요. 공급업체가 줄면 계약도, 감사도, 침해 경로도 줄어요.
- **브랜드 거버넌스를 인프라 차원에서 강제하세요.** 도구는 한 번 작성해 파일이나 수작업 절차가 아니라 데이터로 배포돼요. 밖으로 나가는 결과물은 나가도록 승인된 것과 정확히 같아요.
- **중요한 정보를 사람이 읽을 수 있는 형태로 즉시 만드세요.** 사고 공지, 컴플라이언스 보고서, 경영진 브리핑처럼 구조화된 데이터가 몇 초 만에 지면 품질의 산출물이 돼요. 디자인 병목은 없어요.
- **보안 강화를 공개된 방식으로.** Lolly의 암호화 엔진과 파일 파싱 엔진은 SUSE의 인프라 하드닝 과정을 거치고 있어요. 세계 최대 규모의 기업들에 30년 넘게 보안 기술과 서비스를 제공해 온 원칙이에요. Content Credentials와 로컬 암호화는 설계상 견고하지만, 그 과정이 끝날 때까지는 범위를 한정한 환경에서 시범 적용해 보세요. [도입 & 거버넌스](/info/adoption-governance.html#status)를 참고하세요.

## 무엇을 얻나요

**강력한 크리에이티브 제작 플랫폼.** Lolly 엔진은 각 형식이 낼 수 있는 최고 품질을 목표로 작동해요. 진짜 벡터, 아웃라인 처리된 서체, 인쇄 등급 색상, 편집 가능한 네이티브 결과물이 나와요.

**100% 무료이자 오픈 소스.** SaaS 요금도, 사용량 제한도, 공급업체 종속도 없어요.

**어디서나 작동해요.** 웹 PWA, Mac, Windows, Linux, iOS, Android, CLI, 터미널 TUI까지 같은 엔진, 같은 결과물이에요.

**형식은 들어올 때도, 나갈 때도.** 수십 가지가 들어오고 수십 가지가 나가며, 그중 상당수는 양방향이에요. 전체 정리는 [형식 페이지](/info/formats.html)에, 형식별 자세한 내용은 [내보내기 페이지](/info/exporting.html)에 있어요.

**제작 품질.** 아웃라인 처리된 서체, 별색 지원, 60FPS · 스튜디오에 어울리는 미디어.


## 도구


디자인 자판기라고 생각하면 돼요. 원하는 것을 고르면 결과가 나와요. 언제나요.

도구는 무엇을 어떻게 만드는지 정확히 알고 있는, 바로 쓸 수 있는 크리에이티브 템플릿이에요. 제목과 날짜, 숫자를 넣으면 사양에 맞는 완성된 에셋이 나와요.

디자인 경험은 필요 없어요. 서체나 색상, 간격을 정할 일도 없어요. 도구가 이미 가장 잘 알고 있으니까요. 디자이너든 마케터든 개발자든 AI 에이전트든 결과물은 같아요.

도구는 브랜드를 아는 사람들이 한 번 작성하고, 나머지 모두가 웹 브라우저, 휴대폰, 명령줄, 자동화 파이프라인에서 사용해요. 디자인 결정은 템플릿 차원에 고정돼 있어요. 남은 일은 내용을 채우는 것뿐이에요.
