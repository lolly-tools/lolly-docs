
# Lolly - ランディングページのコピー

スタジオ品質のファイルを数秒で、あなた自身のデバイスで。

求めるときは同一に、必要なときは違うものに。
無料・オープンソース:アカウント不要、カード不要、裏側もなし。


---

## マーケター

### 待たずに、すべて完成形で。

引用カード、イベント用のタイル、各言語版の署名が必要なのは、次のスプリントではなく今日です。デザインツールを開いたことがなくても、Lolly はブランドに沿った完成品を返します。ルールはテンプレートの中にあるので、出力は正しく仕上がります。

- **いくつかの項目を入力すれば、完成したアセットが手に入ります。** フォントを選ぶ必要も、色に迷う必要も、「このロゴで合っているか」と悩む必要もありません。ツールがすでに把握しています。あなたは言葉を用意するだけです。
- **バリエーションは無限、拠りどころはひとつ。** 引用カードを12言語に展開する、40のキャンペーンでブランドロックアップを差し替える、掲載面ごとにすべてのサイズ違いをつくる。いずれもデザインには手を触れずに行えます。すべてはバッチグリッドの表計算から動かせます。CSV を貼り付けるか読み込めば、1行につき1つの完成ファイルが得られます。
- **定型のアセットに制作会社待ちのボトルネックはありません。** メール署名、イベントのカウントダウン、引用カード、QR コード。火曜の午後4時にチームが必要とするものは、すべてセルフサービスで用意できます。
- **画像1枚のために購買手続きは要りません。** 承認すべき新規サブスクリプションも、監査すべきライセンスも、火曜にタイルを1枚必要としただけの人のために買うシートもありません。

## 営業

### どの商談にも、必要なものをそろえて臨めます。

外出先にいて、資料は合っておらず、顧客からは具体的な要望が出ている。Lolly はどんな端末もアセット制作スタジオに変えます。デザイナーも、待ち時間も、言い訳も不要です。

- **何も待つ必要はありません。** 移動中で、商談まで日がなく、いますぐアセットが必要。その場で生成してください。
- **手元の資料をそのまま直せます。** PowerPoint を Lolly にドロップすればスライドがすぐ開くので、残す価値のあるものを選び、鮮明なベクターアートとして再利用できます。あとは数行の Markdown から資料を組み直し、編集可能なネイティブの `.pptx` として送り返せます。
- **一人でキャンペーン全体を。** どの地域のどの担当者も、同じルールに沿って、同じ仕上がりで作業できます。
- **世界水準の体験。** 即座に描き出されたものでも、急ごしらえには見えません。使い捨てのものは一つもないので、やり取りを重ねるたびに少しずつ洗練されていきます。
- **依頼された時点で、作業はすでに終わっています。** 誰かが最初にそのアセットを必要としたときにつくられたツールが、何時でも、どの時間帯でも、数秒で同じものをつくり直します。

## ジャーナリスト

### 速さと正確さのための、編集用ツールキット。

情報編集のスタイルを一度つくれば、動き続けるデータから、そのつど掲載品質のアセットを生成できます。

- **データをそのままビジュアルへ。** 構造化データをチャート、地図、表のテンプレートに接続します。数値を更新すれば、レイアウトは自動的に整います。
- **媒体のスタイルに正確に合わせます。** ツールはタイポグラフィと色の制約を作り込んだ状態で書かれます。ハウススタイルは緩やかな指針ではなく、テンプレートの階層で強制されます。
- **印刷用にも画面用にも。** 同じテンプレートから SVG、CMYK PDF、高解像度 PNG、60fps の動画を書き出せます。ソースは一つで、制作部門が必要とする形式はすべてそろいます。
- **繰り返す記事のための、再利用できる型。** 選挙結果、四半期決算、気象災害。テンプレートを一度つくれば、その記事が出るたびに再利用できます。

## オペレーション

### 日々の出力にも、産業水準の厳密さを。

すべてがマーケティングというわけではありません。配送ラベル、名札の一括作成、コンプライアンスの1枚資料、障害の告知。レイアウトが意味を担い、データが間違っていてはならない出力です。Lolly は配送ラベルを、キャンペーンポスターと同じ厳密さで扱います。

- **構造化データを入力し、正確な出力を得る。** CSVやJSONのテーブルを渡せば、すべてのフィールドがテンプレートの想定どおりの場所に正確に配置されます - 行ごとに1つの完成ファイルです。
- **物理的な精度。** 実寸単位(mm/cm/in/pt)、正確なDPI、塗り足しとトンボ。ラベルプリンターや印刷会社が必要とするものをそのまま渡せます。
- **ロジックはツール内部で実行されます。** バーコード、日付計算、条件付きレイアウト、コントラストチェック - すべて手作業ではなくレンダリング時に計算されます。
- **設計から決定論的です。** 同じ入力からは常に同じファイルが生成されます。監査可能で、再現可能で、CLIやパイプラインから自動化できます。

## メディア & クリエイティブ

### 機械のほうが得意なことは、機械に任せましょう。

あなたが設計するのは仕組みであり、解くのは課題です。使い捨ての制作物ではありません。Lolly は、そのデザイン上の判断を組織全体が使えるツールに変える実行レイヤーです。アセットのたびにあなたが関わる必要はありません。

- **上限はウェブプラットフォームそのものです。** 高度なフィルター、合成、アニメーション、ジェネラティブデザイン。あらゆるウェブ技術がテンプレート作者に開かれており、ブラウザーが描けるものは何であれ、ツールが製品品質で書き出せます。
- **ツールはツールを組み合わせます。** あるツールは別のツールの出力を、生きたアセットとして埋め込めます。自分で QR コードを描く名札や、最新のチャートを差し込むカードが、デザインツールも手作業の合成もなしにつくれます。
- **つくるのはファイルではなくツールです。** ソーシャルカードを1万枚つくるのではなく、1万枚を生成するテンプレートをつくります。時間はデザインの課題に使われ、量産作業には使われません。
- **退屈な作業をなくします。** 最適な組版、ロゴの配置、地図のピンの位置、色のコントラスト確認、書き出しサイズ。いずれもテンプレートの層で解決されます。ルールを一度決めれば、繰り返しは機械に任せられます。
- **変えてはいけないものは固定し、変えるべきものは開放します。** ブランドの制約は作り込みます。実際に変わってよい変数だけを外に出します。ツールそのものがクリエイティブのガードレールになります。

## 開発者

### ビルドパイプラインには、ビジュアルも含めるべきです。

画像はビルド成果物です。そのように扱ってください。Lolly は CLI から実行できるので、ほかのものと同じやり方でアセットを生成できます。再現性を保ち、自動で、ワークフローの一部として行えます。

- **モデルはスケッチに使い、印刷用途には使わない。** プロンプトによる印刷品質メディアの生成はコストが高く、正確ではなく近いだけの結果になりがちです。ツールなら毎回同じファイルを、無料で作成します。
- **再現可能な出力。** 同じ入力からは常に同じファイルが生成されます。URLをコミットしておけば必要なときに再生成でき、画像をリポジトリに入れたりSlackで最新版を探し回ったりする必要がなくなります。
- **メディアをコードベースの外へ。** OGイメージ、QRコード、ソーシャルカード、データビジュアルをGitにバイナリとして保存する代わりに、ビルド時に生成します。
- **アセット内部でロジックを実行。** Code CanvasやChart Creatorのようなツールを使えば、独自のレンダラーを構築することなく、コードスニペットや構造化データ、ライブ値といった実際のコンテンツを本番品質のテンプレート内に配置できます。
- **ロックインなし。** オープンソースのエンジン、ローカル計算、APIキー不要、レート制限なし。

```bash
lolly qr-code --url=https://suse.com --output=og-qr.svg
lolly wordmark --text="Ship it." --output=wordmark.png
```

## AI エージェント

### モデルには、幻覚ではなくツールを使わせてください。

パラメーター付きの URL は数トークンです。クリエイティブブリーフと画像生成では数千トークンかかり、それでも結果は印刷品質になりません。Lolly はエージェントに、決定的で、確認でき、そのまま本番に出せるクリエイティブ層を与えます。


- **製品品質はぶれません。** ツールはごくわずかな計算量で製品品質のアートワークをつくり、しかもローカルで完結します。ツールは作り込まれています。モデルが手を抜いても、レイアウトは手を抜きません。タイポグラフィのルール、色の値、余白。いずれもプロンプト任せではなく、構造として組み込まれています。
- **規模が大きいほどトークンを節約できます。** URL からイベントカードを個別に生成する費用は、同じ出力を生成モデルでプロンプト設計してつくる費用のごく一部です。
- **データをあるべき場所へ。** 構造化された入力は、構造化されたテンプレートに対応づけられます。登壇者名、セッション時刻、製品バージョン。いつでもデザインが想定した位置に正確に配置されます。
- **決定的で、監査でき、バージョン管理できます。** どの出力も入力から再現できます。本番用のアセットに確率的な意外性は生じません。

```
Use Lolly to invite the team to KubeCon.

Parameters:
  title: "KubeCon 2026"
  date: "2026-11-10"
  location: "Atlanta"

Output the file URL.
```

## 大企業の IT・セキュリティチーム

### クリエイティブのファイルがセキュリティリスクであってはなりません。

「見た目を整えるだけ」のために誰かが第三者のサービスへファイルをアップロードするたび、それはいつ起きてもおかしくないデータ流出です。Lolly はその原因そのものを取り除きます。クリエイティブの制作は自社の環境内、あなたの管理下にとどまります。

- **データは端末に留まります。** クラウドでのレンダリングも、アナリティクスも、テレメトリもありません - ユーザーが明示的にトリガーする、ごく一部のネットワークリクエスト以外は一切通信しません。それらは一つずつ[プライバシーポリシー](/info/privacy.html)に明記されています。同僚が作成するものは、それぞれの端末に留まります。オンデバイスのユーティリティが手助けしますが - 何もアップロードされません。暗号化やパスワードの処理さえ端末上で行われます。
- **完全なエアギャップ制御のためのセルフホスト。** 自社のインフラ上にデプロイでき、2つのオプションのサーバーコンポーネントは完全に省略可能です。[Sovereign production](/info/sovereign-production.html)で全体の姿勢を、[Server Surface](/info/server-surface.html)で完全な一覧を確認できます。
- **ベンダー露出面の削減。** 1つのオープンソースプラットフォームが、クリエイティブ制作のために乱立するSaaSサブスクリプション群を置き換えます。ベンダーが少ないほど、契約も監査も侵害ベクトルも少なくなります。
- **インフラレベルでのブランドガバナンスの徹底。** ツールは一度作成され、データとして配布されます - ファイルとしてでも、手作業のプロセスとしてでもありません。世に出るものは、承認された内容そのものです。
- **重要な情報を即座に人間が読める形式に。** インシデント連絡、コンプライアンスレポート、経営層向けブリーフィング - 構造化データが数秒で出版品質のアウトプットになり、デザインのボトルネックがありません。
- **公開の場でのハードニング。** Lollyの暗号処理とファイル解析エンジンは、SUSEのインフラハードニングを経ています - 世界最大級のエンタープライズ向けに30年以上のセキュリティ技術・サービスを提供してきた専門家たちによるものです。Content Credentialsとローカル暗号化は設計段階から堅牢です。詳細は[Adoption & governance](/info/adoption-governance.html#status)をご覧ください。

## 得られるもの

**強力なクリエイティブ制作プラットフォーム。** Lollyエンジンは、お使いのハードウェア上で各フォーマットが生み出せる最高品質を、妥協なく追求します。

**100% 無料でオープンソース。** SaaS の料金も、利用上限も、ベンダー依存もありません。

**どこでも動きます。** Web PWA、Mac、Windows、Linux、iOS、Android、CLI、ターミナルの TUI。エンジンも出力も同じです。

**形式は、入力も出力も。** 読み込みも書き出しも数十種類あり、その多くは双方向に対応しています。内訳は[形式のページ](/info/formats.html)に、各形式の詳細は[書き出しのページ](/info/exporting.html)にあります。

**製品品質。** アウトライン化された文字、スポットカラー対応、60FPS · スタジオでの使用に耐えるメディア。


## ツール


デザインの自動販売機だと考えてください。選べば、結果が出てきます。いつでも同じように。

ツールとは、何をどうつくるかを正確に把握している、すぐ使えるクリエイティブテンプレートです。見出し、日付、数値を渡せば、仕様どおりの完成したアセットが出てきます。

デザインの経験は要りません。フォントや色、余白を決める必要もなく、ツールが最適な答えを知っています。デザイナーでも、マーケターでも、開発者でも、AI エージェントでも、出力は同じです。

ツールはブランドを知る人たちが一度書き、あとは誰もが使えます。ウェブブラウザーからでも、スマートフォンからでも、コマンドラインからでも、自動化されたパイプラインからでも使えます。デザイン上の判断はテンプレートの階層で固定されています。残る作業は、内容を入れることだけです。
